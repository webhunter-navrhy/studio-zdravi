# Koncept – Studio zdraví (Michaela Krumpová)
Zdroj faktů: studio-zdravi.com (Webnode), ceník, kontakt, pobytové balíčky. Fotky ze starého webu NEpoužity (hero je stock, galerie ukazuje záda a tváře klientů bez zjevného souhlasu) → web bez fotek, dokud nepošle vlastní.
1. Páteř: obratle jako rytmus stránky, číslované sekce na svislé ose.
2. Spirála: SM systém = spirální stabilizace páteře; hero s točící se řadou obratlů.
3. Ordinační karta: ceník jako lékařský štítek.
Výběr: 1+2 (páteř se spirálou). Je to přesně obor klientky (záda, držení těla, SPS metoda) a nepotřebuje fotky.
Sekce: hero, co řeším (6 oblastí), cvičení SM systém, ceník, pobyty Viklanka, kde mě najdete, kontakt/rezervace.
Signature: hero SVG – spirálně stočená páteř. Písma: Newsreader (display) + Figtree (text), háčky ověřeny dle references.
Paleta: tmavě petrolejová #1e3c47 + hnědá #95511b + písková #dda87f (z původního loga/brandu), krémový podklad.
Zakázané vzory: žádné (žádné tmavé+zlaté, žádný marquee).
